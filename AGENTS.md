## Code style

- Optimize for readability and maintainability, not terseness.
- Run Prettier on all JS/TS/JSX/TSX files after editing.
- Never compress JSX elements onto a single line.
- Break large React components into meaningful subcomponents.
- Avoid deeply nested inline ternaries and callbacks.
- Extract intermediate variables when they make intent clearer.
- Keep components focused on one responsibility.
- Prefer descriptive names over clever expressions.
